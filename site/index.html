Open source calendar sync

Every meeting.
Every calendar.

calsync keeps your Google and Microsoft 365 calendars in two-way sync. Put something on one and it shows up on the other, so nobody books over a meeting they couldn't see.

The problem

A meeting on one calendar is a double-booking on the other.

Your dentist is on your personal calendar. Your standup is on work. A coworker looks at work, sees an open hour, and books it.

How it works

About 25 minutes, once. Then it runs itself.

  1. 9:00
    Install

    One Docker command, or one pipx install. No database, no account to make.

  2. 9:05
    Connect your calendars

    Open localhost:8484 and sign in to each one. Google and Microsoft each need a free sign-in app of your own; the page walks you through it.

  3. 9:25
    Preview

    See exactly what would be added, updated and removed. Nothing changes yet.

  4. 9:26
    Apply

    From then on calsync keeps every calendar in step, every few minutes.

Safety

It only touches what it made.

Every copy carries a private tag. That tag is the only thing calsync remembers, so there is nothing to migrate or lose.

Preview first

You see what would be added, updated and removed. Nothing changes until you apply.

Only its own copies

calsync edits and deletes only events it created. Your own events are never touched.

Busy only, per calendar

Copies can say just Busy, with no title or location. Private events always do.

Stops before a big delete

If a run would remove more than half of a calendar's copies, it stops and waits. A calendar that won't load is left alone.

No double invites

A meeting already there through a shared invite isn't copied again. Declined and cancelled events are skipped.

One-button undo

Copies carry no reminders. One button, or calsync purge, removes every copy it made.

Before you start

What to know first.

Google
Needs a free sign-in app of your own.
Microsoft
Needs one too. Some school and work tenants block outside apps. A published .ics link still works, one way.
Window
The next 120 days. Repeating events are copied as single occurrences.
Hosted version
There isn't one. The machine running calsync needs to be on.

Install

Pick one.

With Docker

git clone https://github.com/jakescalesAI/calsync
cd calsync
docker compose up -d
docker compose logs calsync

Open http://localhost:8484. The first visit asks for the setup code from those logs. Then you choose a password.

With Python 3.10 or newer

pipx install git+https://github.com/jakescalesAI/calsync
calsync web

The same page opens at http://localhost:8484.
