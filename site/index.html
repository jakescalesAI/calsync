Two-way sync

One schedule. However many calendars.

Each writable calendar gets one tagged copy of every real event from the others. Move the meeting once and every copy follows. A published .ics link can join in too, one way.

Before you start

What to know first.

Google
Needs a free sign-in app of your own.
Microsoft
Needs one too. Some school and work tenants block outside apps. A published .ics link still works, one way.
iCloud and CalDAV
Needs an app password from your provider. Fastmail, Yahoo, AOL, Zoho and Nextcloud work the same way.
Proton
Proton has no way to write in, so its calendars come through a share link, one way.
Booking apps
Connect Calendly, Cal.com or similar to one synced calendar. There is nothing to add in calsync.
Window
The next 120 days. Repeating events are copied as single occurrences.
Hosted version
There isn't one. The machine running calsync needs to be on.

Install

Pick one. Both take a minute.

With Docker

git clone https://github.com/jakescalesAI/calsync
cd calsync
docker compose up -d
docker compose logs calsync

Open http://localhost:8484. The first visit asks for the setup code from those logs. Then you choose a password.

With Python 3.10 or newer

pipx install git+https://github.com/jakescalesAI/calsync
calsync web

The same page opens at http://localhost:8484.

On Windows, get pipx first, then open a new terminal:

py -m pip install --user pipx
py -m pipx ensurepath
