Install without Docker

One Python package gives you the web page and the command line.

Install

You need Python 3.10 or newer, Git and pipx. To get pipx on Windows, run this, then open a new terminal:

py -m pip install --user pipx
py -m pipx ensurepath

On a Mac, use brew install pipx. On Debian or Ubuntu, use sudo apt install pipx. Then:

pipx install git+https://github.com/jakescalesAI/calsync
calsync web

Open http://localhost:8484. It opens straight in, with no account and no password, and only this computer can reach it. The page syncs in the background while calsync web runs.

To update later, run pipx upgrade calsync.

pipx also installs the two packages CalSync needs: python-dateutil for repeating events and tzdata for time zones. Windows has no time zone data of its own, so if you run calsync_web.py straight from a copy of the code, first run py -m pip install python-dateutil tzdata.

Syncing runs for as long as calsync web is running, so leave that window open. On Windows, Task Scheduler can start it when you sign in.

The command line

calsync web
The web page and background sync.
calsync setup
Store your Google or Microsoft sign-in app.
calsync auth
Sign in an account: google, outlook or ics.
calsync calendars
List the calendars on your accounts.
calsync add
Add a calendar to the sync.
calsync remove
Take a calendar out of the sync.
calsync run
One sync pass. Add --dry-run to preview.
calsync purge
Delete the copies CalSync made.
calsync status
Show the calendars and the last run.
calsync new
Add an event from plain text.
calsync mcp
Tools for AI agents. See AI agents.

Using only the command line

calsync setup google                 # store the sign-in app. Hidden prompts.
calsync auth google personal         # sign in. The label is yours to choose.
calsync setup microsoft
calsync auth outlook work            # sign in with a device code
calsync auth ics school              # a published .ics link, read only

calsync calendars                    # list calendars on every account
calsync add main personal primary
calsync add work work CALENDAR_ID --busy-only --skip main
calsync add school school ics --read-only
calsync status

The arguments are NAME ACCOUNT CALENDAR_ID, then any flags. --busy-only, --read-only and --skip OTHER_NAME match the three options on the web page. A .ics link is a single calendar with the ID ics. For a feed of due dates, such as school assignments, --free stops its items marking you busy, and --only TEXT keeps only items whose UID holds that text. calsync remove NAME takes a calendar out.

Preview, then sync

calsync run --dry-run    # show what would change. Changes nothing.
calsync run              # one sync pass

Put it on a timer

If you do not run calsync web, run calsync run every few minutes. The repository has a sample systemd service and timer in its deploy folder. With cron, every 5 minutes:

*/5 * * * * calsync run >> $HOME/.calsync/run.log 2>&1

Cron has a small environment. If you set CALSYNC_HOME, set it on the cron line too, and use the full path to calsync.

Quick add

Add an event from plain text. It goes on your main calendar, then CalSync syncs so it appears everywhere.

calsync new Dentist tomorrow 3pm 1h
calsync new Dentist tomorrow 3pm 1h --check   # show how it was read, add nothing

The way out

calsync purge --dry-run   # list the copies calsync made
calsync purge             # delete them. Your own events stay.
