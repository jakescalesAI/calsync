Settings and environment

Most settings are on the CalSync page. A few live in environment variables.

On the page

The page has three tabs. Sync lists your calendars, adds new ones and runs the sync. Calendar shows a day, a week or a month, where you can add, change and move events: see The Calendar tab. Settings holds the rest.

  • How often it runs. Every 2, 5, 10, 15, 30 or 60 minutes. The default is 5.
  • Time zone. Used for quick add text, agendas and .ics times that name no zone. A second time zone can show beside it on the Calendar tab.
  • How far to sync. Days back and ahead. The default is 0 back and 120 ahead.
  • Quick checks. On by default: every minute, CalSync asks Google and Microsoft calendars whether anything changed, with one small request each, and syncs at once if so. iCloud, other CalDAV servers and .ics links sync on the interval.
  • Password. You can change it in the settings.
  • Recovery code. Make a new one at any time. The old one stops working.
  • Quick add puts events on. The calendar quick add writes to. Pick the one your booking page reads, so a new event blocks that time there at once.

Quick add, overlaps and skipping

  • Quick add. Type plain words on the Calendar tab, like breakfast with friends tomorrow 9am for 2 hours. You see a one-line preview first. After you add it, CalSync syncs right away.
  • Guests and reminders. Email addresses become guests, who get a normal invite from your Google calendar only after you tick Send the invites. remind me 1h before sets a reminder.
  • Overlaps. If the time is already busy, the preview names what it overlaps, and the button says Book anyway.
  • Skip copying this one. Open an event and skip it, for example a class that's cancelled. Its copies go, so the time opens on your other calendars. The original stays where it is. Skipped events are listed below the calendar with Undo.

No password

CalSync has no account and no password. It runs on your computer, and only that computer can reach the page. An older install that had a page password just stops asking for it.

Environment variables

CALSYNC_HOME
The folder for config and sign-in tokens. Default ~/.calsync. Keep it private to your user.
CALSYNC_PORT
The port for the page. Default 8484. In Compose, it sets the port published on your machine.
CALSYNC_BIND
The address the page listens on. Default 127.0.0.1. Any other address also needs CALSYNC_ALLOW_REMOTE=1.
CALSYNC_ALLOW_REMOTE
Set to 1 to let the page listen beyond this computer. The page has no password, so anyone who can reach it can read and change your calendars. The Docker image needs it, because a container has its own network; Compose sets it and publishes the port to this machine only.
CALSYNC_HOSTS
With CALSYNC_ALLOW_REMOTE=1, extra host names allowed to reach the page, separated by commas.
CALSYNC_PUBLIC_URL
The https address, if you put CalSync behind your own proxy. It is used as Google's sign-in return address. With it, Google and Microsoft also tell CalSync the moment a calendar changes, at /hook/google and /hook/microsoft, and it syncs within seconds.
CALSYNC_TZ
The time zone for quick add text, agendas and .ics times that name none.

With Docker Compose, put these in your shell or in a .env file next to compose.yaml. Compose passes CALSYNC_TZ, CALSYNC_HOSTS, CALSYNC_PUBLIC_URL and CALSYNC_PORT through.

Reaching it from other machines

Only the computer running CalSync can reach the page, and that's what keeps it yours: there's no password. It answers only at http://localhost or http://127.0.0.1 with its own port.

If you really want it elsewhere, set CALSYNC_ALLOW_REMOTE=1, CALSYNC_BIND, and CALSYNC_HOSTS for the name you use. Then whoever reaches that address can read and change your calendars, so only do it behind a proxy that signs you in, or on a private network only you are on.

Optional notes features

Three extras are switched on in config.json inside the CalSync folder. They are all optional.

quick_add
New lines starting with "- " in a Markdown note become events.
agenda
Writes a Markdown agenda and refreshes the Calendar section of daily notes, for Obsidian-style folders.
export
Writes one .ics file per source calendar, with real events only.
