Settings and environment

Most settings are on the calsync page. A few live in environment variables.

On the page

The page has three tabs. Sync lists your calendars, adds new ones and runs the sync. Calendar shows a week or a month of what calsync sees: pick one calendar to see what is on it now, with the copies calsync made striped. Settings holds the rest.

  • How often it runs. Every 2, 5, 10, 15, 30 or 60 minutes. The default is 5.
  • Time zone. Used for quick add text, agendas and .ics times that name no zone.
  • Password. You can change it in the settings.
  • Recovery code. Make a new one at any time. The old one stops working.
  • Quick add puts events on. The calendar quick add writes to. Pick the one your booking page reads, so a new event blocks that time there at once.

Quick add, overlaps and skipping

  • Quick add. Type plain words on the Calendar tab, like breakfast with friends tomorrow 9am for 2 hours. You see a one-line preview first. After you add it, calsync syncs right away.
  • Guests and reminders. Email addresses become guests, who get a normal invite from your Google calendar only after you tick Send the invites. remind me 1h before sets a reminder.
  • Overlaps. If the time is already busy, the preview names what it overlaps, and the button says Book anyway.
  • Skip this one. In the week view, open an event and skip it, for example a class that's cancelled. Its copies go, so the time opens on your other calendars. The original stays where it is. Skipped events are listed below the calendar with Undo.

Forgot your password

calsync runs on your own computer, so there is no account and no email reset. Both ways back work only on the computer calsync runs on, never from anywhere else.

  • From a terminal on that computer. Run calsync reset-password. With Docker, run docker compose exec calsync calsync reset-password. Anyone who can do this can already read calsync's folder, so it gives nothing away.
  • With your recovery code. The page showed it once when you chose your password. On the sign-in page, choose Forgot password? and enter it with a new password. Each code works once.

Either way, every browser is signed out and you get a new recovery code.

Environment variables

CALSYNC_HOME
The folder for config and sign-in tokens. Default ~/.calsync. Keep it private to your user.
CALSYNC_PORT
The port for the page. Default 8484. In Compose, it sets the port published on your machine.
CALSYNC_BIND
The address the page listens on. Default 127.0.0.1. The Docker image listens on all addresses inside the container, and Compose publishes the port to this machine only.
CALSYNC_HOSTS
Extra host names allowed to reach the page, separated by commas.
CALSYNC_PUBLIC_URL
The https address, if you put calsync behind your own proxy. It is used as Google's sign-in return address.
CALSYNC_TZ
The time zone for quick add text, agendas and .ics times that name none.

With Docker Compose, put these in your shell or in a .env file next to compose.yaml. Compose passes CALSYNC_TZ, CALSYNC_HOSTS, CALSYNC_PUBLIC_URL and CALSYNC_PORT through.

Reaching it from other machines

By default only the machine running calsync can reach the page. Before you expose it to the internet, put it behind your own HTTPS proxy. Then set CALSYNC_PUBLIC_URL to the proxy's https address and CALSYNC_HOSTS to its host name. Sign-ins and tokens are on that machine, so treat it like a password manager.

Through a proxy, the first visit always asks for the setup code, even though the proxy runs on the same machine. Wrong passwords and setup codes are limited to a few a minute, so the page can't be guessed, and someone hammering it can lock it for a minute at a time. A private network such as a VPN is safer than the open internet.

Lost a laptop that was signed in? Settings has Sign out on every device, which ends every session at once.

Optional notes features

Three extras are switched on in config.json inside the calsync folder. They are all optional.

quick_add
New lines starting with "- " in a Markdown note become events.
agenda
Writes a Markdown agenda and refreshes the Calendar section of daily notes, for Obsidian-style folders.
export
Writes one .ics file per source calendar, with real events only.
