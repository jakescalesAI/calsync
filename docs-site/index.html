calsync docs

calsync keeps your Google, Microsoft 365, iCloud and other CalDAV calendars showing the same events. You run it yourself. These pages cover everything from install to troubleshooting.

The order to do things in

  1. Install calsync, with or without Docker.
  2. Make a free sign-in app for Google or Microsoft if you use them. iCloud and other CalDAV calendars only need an app password.
  3. Open the page at http://localhost:8484, add your calendars and sign in.
  4. Press Preview changes. Read the plan.
  5. Press Apply and keep syncing.

What you need

  • A machine that stays on, such as a home server, a spare computer or a small VPS.
  • Docker with Compose, or Python 3.10 or newer.
  • About 10 minutes to make a sign-in app for each of Google and Microsoft, or a minute for an app password on iCloud and CalDAV.

There is no hosted version of calsync. There is no account with us.
