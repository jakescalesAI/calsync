calsync docs

calsync keeps your Google and Microsoft 365 calendars showing the same events. You run it yourself. These pages cover everything from install to troubleshooting.

The order to do things in

  1. Install calsync, with or without Docker.
  2. Make a free sign-in app for each provider you use: Google, Microsoft, or both.
  3. Open the page at http://localhost:8484, add your calendars and sign in.
  4. Press Preview changes. Read the plan.
  5. Press Apply and keep syncing.

What you need

  • A machine that stays on, such as a home server, a spare computer or a small VPS.
  • Docker with Compose, or Python 3.10 or newer.
  • About 10 minutes to make a sign-in app for each of Google and Microsoft.

There is no hosted version of calsync. There is no account with us.
